# Description of all the experiments run in Tesdal et al (2026): The contribution of sterodynamic changes to the uncertainty of regional sea-level projections over the 21st century.    

The [Tesdal_et_al_2026_AGUAdvances](https://github.com/jetesdal/Tesdal_et_al_2026_AGUAdvances/tree/main/experiments) github repo contains details of processing, analysis, and plotting code used in the Tesdal et al (2026) paper. 

For detailed descriptions of all experiments run as part of this work, please refer to the links below.

1. Detailed descriptions of the [28 FACTS experiment setups](https://github.com/jetesdal/Tesdal_et_al_2026_AGUAdvances/tree/main/experiments#experiments-used-in-the-tesdal-paper).   
1. The [individual configuration files](https://github.com/jetesdal/Tesdal_et_al_2026_AGUAdvances/tree/main/experiments/configurations) used to run all experiments conducted in this work.
    * A [configuration guide](https://github.com/jetesdal/Tesdal_et_al_2026_AGUAdvances/blob/main/experiments/CONFIGURATION_GUIDE.md#experiments-and-configuration-files) has also been provided that explains details of variables, specifics of `config.yml`, and `location.lst` and the generated `workflows.yml` that are used. 

:bulb: To replicate the experiments in the [configuration](https://github.com/jetesdal/Tesdal_et_al_2026_AGUAdvances/tree/main/experiments/configurations) folder, please make sure to download the `tlm_sterodynamics_cmip6_v20221104_data.tgz` from Zenodo. See  [FACTS TLM input dataset](https://github.com/jetesdal/Tesdal_et_al_2026_AGUAdvances/blob/main/cmip6/TLM_INPUT_DATA.md#definitive-facts-tlm-input-dataset) for more datils on this dataset.
